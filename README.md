# ⚡ Rwaft

### Ship your code. Get a live URL.

**Rwaft turns your GitHub repository into a live website in seconds.**

No server setup.
No manual builds.
No complicated deployment configuration.

Just paste your repository and **deploy.**

---

## 🚀 Deploy from GitHub

```text
GitHub Repository
       ↓
     Rwaft
       ↓
   Build & Deploy
       ↓
   🌍 Live Website
```

### How it works

1. **Paste your GitHub repository**
2. **Rwaft builds your project**
3. **Your website goes live**
4. **Share the generated URL**

That's it.

---

## ✨ Why Rwaft?

### ⚡ Fast

Go from source code to a live website without manually configuring servers.

### 🧑‍💻 Developer Friendly

Built around the workflow developers already use — **GitHub → Deploy → Live.**

### 📦 Zero Deployment Hassle

Forget about configuring Nginx, setting up servers, or manually uploading build files.

### 🌐 Instant URLs

Every deployment gets a publicly accessible URL.

### 🔄 Built for Continuous Deployment

Push your code, deploy again, and ship your latest version.
